How to turn on the handwriting keyboard

Android (Gboard): Settings → System → Languages → On-screen keyboard → Gboard → Languages → English → turn on Handwriting. Then tap the box and use the keyboard key to switch to handwriting.
Samsung: keyboard settings → Languages and types → English → add Handwriting.
iPad with Apple Pencil: Settings → Apple Pencil → Scribble. Write straight into the box.
iPhone: no English finger-handwriting keyboard. Use the normal keyboard.
